## 🌟 About CareerTrackAI

Balancing consistency, skill-building, and project learning can often feel overwhelming. **CareerTrackAI** is a centralized SaaS platform designed to turn your developer preparation journey into an interactive, gamified experience. Complete with an intuitive **light and dark mode toggle**, it looks stunning day or night! 🌓✨

---

## ✨ Key Features

* 🔥 **Streak & Consistency Tracker:** Logs daily coding activity, tracks consistency percentages, and visualizes progress via an interactive calendar view.
* 🧠 **AI Notes & Book Finder:** Powered by Gemini and OpenRouter to generate multi-page structured study notes with direct reference shortcuts to LeetCode, NeetCode, and GeeksforGeeks, plus PDF export functionality.
* 📊 **DSA Sheet & Progress Tracker:** Topic-wise breakdowns, problem difficulty filters, and real-time progress rings to monitor problem-solving milestones.
* 🎯 **Placement Readiness Analytics:** Dynamic score rings and milestone tracking to evaluate job readiness at a glance.
* 🔒 **Secure Authentication & Automated Emails:** Built-in password resets and contact form handling powered by Brevo and Passport.js.

## 🛠️ Tech Stack Behind the Scenes

### **Frontend**
* **Framework:** React (Vite)
* **Styling:** Tailwind CSS & Custom CSS
* **Icons & UI:** Custom SVG components

### **Backend & Database**
* **Runtime & Framework:** Node.js, Express.js
* **Database:** MongoDB Atlas (Mongoose ODM)
* **Authentication:** Passport.js (Secure Sessions)
* **File Management:** Multer

### **APIs & Integrations**
* **AI Engine:** Google Gemini & OpenRouter APIs
* **Transactional Emails:** Brevo API

### **Deployment**
* **Frontend:** Vercel
* **Backend:** Render
